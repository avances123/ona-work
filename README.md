# Ona Work

Plataforma educativa y entorno interactivo de estudio para Ona (1.º de Primaria / Currículo clásico de EGB).

## Objetivos del Proyecto

- **Práctica interactiva guiada:** cálculo formal (tablas, operaciones mixtas), lógica visual (series, sudokus 4×4) y ortografía contextual.
- **Enfoque pedagógico:** fomento del esfuerzo sostenido, concentración y razonamiento socrático.
- **Despliegue:** Aplicación Angular estática alojada en GitHub Pages para acceso directo y liviano desde su portátil (`fa-ona`).

## Stack Tecnológico

- **Framework:** Angular (SPA)
- **Alojamiento:** GitHub Pages
- **Integración:** Entorno adaptado para navegación directa en Wayland/Hyprland
